# Emmanuel Oduro Larbi Portfolio

This is a static GitHub Pages version of Emmanuel Oduro Larbi’s digital marketing portfolio. It uses plain HTML and CSS, so no installation or build command is required.

## Deploy on GitHub Pages

1. Create a new GitHub repository, or open the existing `portfolio` repository.
2. Upload everything in this folder to the repository root. Keep the `portfolio` asset folder intact.
3. Commit the files to the `main` branch.
4. Open **Settings → Pages** in the repository.
5. Under **Build and deployment**, choose **Deploy from a branch**.
6. Select the `main` branch and the `/ (root)` folder, then save.

The website will be available at `https://YOUR-USERNAME.github.io/REPOSITORY-NAME/` after GitHub finishes publishing it.

## Main files

- `index.html` contains the complete page content.
- `styles.css` contains the responsive design.
- `portfolio/` contains the portraits, project images and downloadable CV.
- `favicon.svg` is the browser-tab icon.

All website paths are relative, so the site works from a GitHub Pages project URL or a custom domain.
